🏥 NHS Mental Health Risk Prediction

AIML-4: Live Model Demonstration

May 2026

What Does This Model Do?

  • Predicts 30-day readmission risk
  • Based on PHQ-9 (depression) + GAD-7 (anxiety)
  • Input: Patient demographics + questionnaire scores
  • Output: Risk Score (0-10) + Classification

The Model

  • Algorithm: XGBoost + Random Forest + Logistic Regression
  • Features: 14 input features
  • Model: ensemble_v3.pkl
  • API: FastAPI at /predict

Live Demo Results

  • -> Risk: 9.95 / 10.0 = HIGH
  • P002 - 34yo, PHQ-9=3, GAD-7=2
  • -> Risk: 0.02 / 10.0 = LOW
  • P003 - 52yo, PHQ-9=20, GAD-7=18

Performance Metrics

Limitations
