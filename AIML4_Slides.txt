============================================================
SLIDE 2: WHAT IT DOES
============================================================
Purpose:
- Predict 30-day readmission risk for mental health patients
- Based on PHQ-9 (depression) + GAD-7 (anxiety) scores

Input → Output:
[Patient Data] → [Ensemble Model] → [Risk Score 0-10]

Use: Decision support for clinicians (NOT replacement)

============================================================
SLIDE 3: THE MODEL
============================================================
Technical Details:
- Algorithm: XGBoost + Random Forest + Logistic Regression
- Features: 14 input features
- Model: models/ensemble_v3.pkl
- API: FastAPI at /predict

Key Features:
- age_band_code
- phq9_score, gad7_score
- comorbidity_count
- high_deprivation
